# Дом пропавших дорог — инструкции для Codex

Codex владеет конвейером ассетов и независимым плейтестом. Сначала прочитать `CLAUDE.md` (общий контракт и канон), затем `Docs/CURRENT_STATE.md`, `Docs/STYLE_BIBLE.md` и `assets/manifest.json`.

## Что делает Codex
- `pipeline/3d/` — Meshy по API (ключ из `MESHY_API_KEY` в окружении): персонажи с походкой и переезжающие предметы (школьная дверь, зеркала ЗМ/ЗГ/ЗП, колокол, лодка, знак). image-to-3D по утверждённому листу → авториг → пресеты движений → GLB.
- `pipeline/render/` — Blender из командной строки: фиксированная камера под углом комнаты, 8 направлений, кадры циклов → `assets/characters/<name>/<dir>/<frame>.png` + стилизация под живописный фон.
- `pipeline/2d/` — пакетная 2D-генерация предметов и состояний по техзаданиям манифеста через Meshy text-to-image / image-to-image (nano-banana-2 по умолчанию, `remove_background: true`), очистка краёв, проверка размера и опорной точки против манифеста.
- `pipeline/voice/` — озвучка: реплика + поля режиссуры (`emotion`, `delivery`, `pause_before`) → TTS API → нормализация громкости → обрезка тишины → `assets/voice/<lang>/<line_id>.ogg` + манифест с хешем текста (перегенерация только изменённых строк). Массовая запись — только после пометки `text_freeze: true` в `data/story/meta.json`.
- Независимый плейтест каждой сборки из `build/`: список дефектов в `Docs/PLAYTEST_<дата>.md` — что нажал, что ожидал, что увидел. Не чинить код игры.

## Чего Codex не делает
- Не правит `game/`, `data/`, `tools/`, `Docs/` кроме своих отчётов плейтеста и `Docs/ASSET_PROVENANCE.md`.
- Не меняет канон, тексты реплик и условия сцен.
- Не покупает кредиты и не меняет планы сервисов; при нехватке кредитов — остановиться и спросить Директора.
- Не кладёт ключи в репозиторий.

## Провенанс
Каждый ассет: источник (модель, версия, задание, дата), входные референсы, лицензия. Запись в `Docs/ASSET_PROVENANCE.md` обязательна до отметки «готово» в манифесте.
