Дом пропавших дорог — восемь листов NPC v2

Состав: Нина — 67 лет; Илья — 32 года; Варвара — около 30 лет; Ульяна — 8 лет; Митя — 37 лет; Пелагея — 40 лет; Павел — 48 лет; Тамара — 53 года.

Каждый PNG: 3264×2448, анфас, профиль вправо и спина, фон #DEDEDC.
У каждого листа — отдельный README с ограничениями и точными запросами.

Размеры файлов не означают нативную генерацию в этом разрешении. Нативное разрешение, увеличение, ограничения кистей, поз, реконструированных деталей, платков и соответствия между видами указаны по персонажам.

Ракурсы внутри каждого листа выровнены по высоте. Листы разных персонажей не задают общую шкалу их относительного роста.
Это иллюстрированные референсы, а не метрически точные проекции единой готовой 3D-модели.
