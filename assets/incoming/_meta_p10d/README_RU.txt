ПРИМЕНЕНИЕ
Комнатные слои накладывать в (0,0), масштаб 1:1, normal alpha, 100%. Холсты и прозрачные поля не обрезать. Альфа straight, цвет sRGB.
Для R3: R3_bg (либо полная R3_day) → лодка → R3_fg_rope_stop. Другие существующие передние планы оставить согласно сцене.
Для O3 ночь сначала наложить RGBA O3_night на O3_bg; затем эту заплату. Для Z3 сначала наложить RGBA Z3_state_water_low на Z3_bg; затем снежный слой. Прозрачные ночные/сезонные слои нельзя просто читать как RGB.
Новые крупные планы непрозрачны целиком. На дощечке нет текста: строки наносит игра в [470,180,1200,770).

ПРОВЕРКИ
Все PNG читаются; размеры, нулевая альфа вне разрешённых зон, сплошная непрозрачность заплат H2/O3 и совпадение их краевых 2px с основами проверены скриптом. Рама H4 исключена из маски. Визуальная проверка выполнена по JPEG-наложениям.
Полупрозрачность мелких кромок оценивается на основе; в игровом движке не проверялась. Буквы на исходных ящиках H2 вне новых слоёв — часть исходника.
