Каждый из трёх слоёв H2 накладывается на фон с верхним левым углом (0,0), масштабом 1:1, без обрезки прозрачных полей.

Если при импорте движок автоматически обрежет прозрачные поля, необходимо восстановить смещение из assets_manifest.json; предпочтительно сохранять полный холст.

ТЕКСТ ПЛАНА
Для 6–7 строк использовать свободную нижнюю область примерно x=150, y=625, width=1360, height=245.
Точный шрифт, размер и межстрочный интервал выбирает игра. Проверить фактический русский текст в этой области после наложения.
Никаких сюжетных надписей на план, рисунок или бирку не нанесено.
