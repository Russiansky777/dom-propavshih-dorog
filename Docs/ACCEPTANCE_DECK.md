# Приёмка Deck — управление с геймпада (Steam Deck)

Что проверяем: игра целиком проходится с геймпада — на Steam Deck или с любым контроллером (Xbox, PlayStation, Switch Pro) на ПК. Геймпад «ведёт мышь»: ничего в комнатах, панелях и мини-играх не переделано, поэтому мышь и клавиатура работают как раньше. Решения — `Docs/DECISIONS.md` 09.11.

## Где проверять

- **Windows-сборка** из релиза latest — сборка 09.11 вечером (run 42677910736), та же, что для `Docs/ACCEPTANCE_HANDS.md`: https://github.com/Russiansky777/dom-propavshih-dorog/releases/tag/latest → `DomPropavshihDorog.exe`.
- Подключите контроллер до или после запуска — подсказки появятся при первом нажатии кнопки или движении стика.

## Кнопки

| Кнопка | Что делает |
| --- | --- |
| Левый стик | курсор (чем сильнее наклон, тем быстрее) |
| Правый стик | курсор медленно — для точного прицеливания в мини-играх |
| A | щелчок: идти, взять, осмотреть, дальше по реплике; удерживать + стик — перетаскивать (фонарь, канат, узел) |
| B | вернуть предмет из руки в сумку; если в руке пусто — «назад» (закрыть, пауза) |
| Start | пауза (меню) |
| X | журнал |
| Y | подсветить всё, с чем можно что-то сделать (как пробел) |
| L / R (бамперы) | взять в руку предыдущий / следующий предмет из сумки |
| Крестовина | курсор прыгает к ближайшему предмету или выходу в эту сторону |

## Критичное

| № | Что сделать | Как должно работать | Ок? |
| --- | --- | --- | --- |
| 1 | Нажать любую кнопку геймпада в комнате | Внизу появляется строка подсказок «A — действие · B — назад · …»; шевельнёте мышь — строка исчезает | |
| 2 | Пройти первый день целиком только геймпадом (почта, ключ, дом Дуни) | Всё доступно: ходьба, реплики, сумка, предметы в руке, журнал, выходы | |
| 3 | Крестовина в любой комнате | Курсор прыгает от предмета к предмету, от выхода к выходу | |
| 4 | Мини-игры: колокол и клинья, бревно (ворот), фонарь, канат на переправе, рыбалка | Играются кнопкой A и стиком; перетаскивание — A удерживать + стик | |
| 5 | Рыбалка с Митей | Лёгкий толчок, когда поплавок уходит под воду; сильный — когда рвётся леска | |
| 6 | Колокол в мастерской, стук в ставню (M19), засов | Короткий толчок вместе с ударом | |
| 7 | Пауза → Настройки | Есть «Курсор» (скорость) и «Вибрация геймпада» (вкл/выкл) — только когда подключён контроллер | |

## Важное

| № | Где | Как должно быть | Ок? |
| --- | --- | --- | --- |
| 8 | Шаги, двери, меню, мел, ложечки Тихона | Без вибрации (ритм с Тихоном — на слух) | |
| 9 | Мышь и клавиатура без геймпада | Всё как раньше, подсказок нет, в настройках строк геймпада нет | |
| 10 | Читаемость на экране Deck | Подсказки и реплики читаются (на Deck текст подсказок ≈ 16 px при норме Valve ≥ 9, лучше 12) | |

## Оценивать не нужно

- Значки кнопок картинками — подсказки текстом (так договорились 09.11).
- Steam Input / облачные сохранения / ачивки Steam — после регистрации в Steamworks.
- Полосы сверху и снизу на Deck (экран 16:10, игра 16:9) — допустимо по Valve.

## Как ответить

Номер и «ок» / что не так — сообщением или файлом, как обычно.
