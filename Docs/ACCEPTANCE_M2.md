# Приёмка M2 — день второй (блок 2), чеклист для Директора

Что проверяем: день второй по `Docs/SCENARIO_FINAL.md` §7 — от утра у печи до встречи с Митей на дальней опоре. Мельница, зеркало конторы и колокол, крюк по звону, затвор, мамино зеркало, плита и канат, три огня, пустая лодка с лентой, переправа. Дальше (улица Ольховки, мама, M19) — техническая граница «дальше не собрано».

## Где проверять

- **Браузер:** https://russiansky777.github.io/dom-propavshih-dorog/ — после обновления сборки Ctrl+F5. Номер версии: https://russiansky777.github.io/dom-propavshih-dorog/version.txt
- **С чего начать:** пройти день первый до «Ночи у печи» (вернуться из школы через дверь в галерею). Если день первый уже пройден в этом браузере — «Меню» → строка **«День второй»** → «Загрузить».
- Управление — только мышь. Клик по полу — идти; клик по подписанному месту — подойти и сделать; предмет в сумке — выбрать, потом кликнуть, к чему применить. В крупном плане — кнопка «Закрыть» внизу справа (или Esc). Пробел — показать все места, куда можно кликнуть.
- Прохождение дня второго — 15–25 минут.

## Как ответить

Одним сообщением: номера пунктов «ок» и «не ок»; для «не ок» — что произошло (можно скриншот). Замечания по тексту — первые слова строки. Если что-то зависло — номер шага и что было на экране.
