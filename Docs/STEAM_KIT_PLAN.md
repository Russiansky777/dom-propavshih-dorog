## Порядок работ, когда снимем паузу
1. **Тексты.** Сверить обещания RU/EN со сборкой. Заранее видно: «рама зеркала… комната в стекле» и «мельничные бумаги» — эпизод E2, ещё не собран; «недоставленное письмо», «угол Тихона», «решайте, как помочь» — проверить по данным. EN — перевод страницы, не обещание английского интерфейса/озвучки. Стиль RU не править — только точечный список несоответствий.
2. **Графика.** Размеры брать из официальной документации Steamworks в момент работы (`partner.steamgames.com/doc/store/assets`, `/assets/rules`), CSV пакета — только подсказка. Пропорции исходников почти совпадают с целями (обрезка безопасных краёв), кроме **library_hero 2206×713 → 3840×1240** (увеличение в 1,74 раза — нужен качественный апскейл или новый исходник крупнее; не растягивать молча). Логотип сохранить с прозрачностью. Иконкам достижений нужны и **серые «не получено»** — Steam требует оба состояния. Малую капсулу проверить в реальном размере.
3. **Скриншоты и трейлер — из настоящей сборки.** Захват: Godot Movie Maker (`--write-movie`, фиксированные 60 fps, 1920×1080, звук игры в той же записи) под Xvfb + Mesa llvmpipe (оба есть в контейнере) — запись не зависит от скорости машины. Действия ведёт скриптовый бот реальными событиями ввода от сохранений перед M03, M05 и входом в O1. Кодирование ffmpeg: H.264 + AAC 48 кГц стерео, 15–25 Мбит/с.
   - Трейлер на странице Steam стартует **без звука** → реплики субтитровать в кадре, крючок в первые 2–3 с, игра с первого кадра, логотип в конце.
   - Версии: чистая без титров; RU; EN-субтитры; с призывом «в желаемое» и без него (призыв — только когда страница открыта); вариант B с ZAKADR (2 фразы) — по желанию Директора.
   - Зимний ветер для O2 — сгенерировать конвейером (ElevenLabs sound generation; параметры API проверить по документации), пригодится и в самой игре.
   - MP4 ~120–180 МБ больше лимита GitHub на файл (100 МБ) → не в git; Директору — файлом в разговор (копия для просмотра) + исходники монтажа.
4. **Достижения.** Данные `data/story/achievements.json` (API-имена, условия по флагам, скрытые) + автозагрузка AchievementDirector; Steam-часть через GodotSteam (MIT) — только с настоящим AppID, тестовый не подставлять; веб работает без Steam. Восстановление после загрузки и повторная отправка (SetAchievement → StoreStats) при следующем запуске. Валидатор: каждый флаг условия существует в flags.json; достижения E2+ — «planned», пока сцен нет.
5. **Раскрытие ИИ и права.** Сверить `ai_disclosure.txt` с `Docs/ASSET_PROVENANCE.md` (ChatGPT-арт, Meshy, Suno, ElevenLabs). Права на коммерческое использование каждого сервиса проверить по их действующим условиям и тарифу Директора — это зависимость Директора, не угадывать.
6. **Выдача.** Папки store_graphics/, library_graphics/, screenshots/, trailer/, achievements/, texts/ + таблица «файл → поле Steam → готов/требует действия» + `Docs/ACCEPTANCE_STEAM.md`.
