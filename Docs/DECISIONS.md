## Принятые

- 2026-10-17 · **Движок Godot 4.7.x, GDScript.** Браузер (itch.io) + Windows/macOS/Linux из одного проекта. C# отпадает: нет веб-экспорта (официальный прототип без сроков). Текстовые .tscn/.gd, CLI, GdUnit4 — агент может собирать и проверять без человека. · Разбор от 17.10, принято Директором («приступаем»).
- 2026-10-17 · **Контент как данные.** Сценарий живёт в `data/story/*.json`; `tools/validate_story.py` — обязательная проверка перед коммитом. Литературный текст в `story_source/` только читается. · Claude Code.
- 2026-10-17 · **Meshy — источник персонажей и переезжающих предметов (3D → спрайты), а также 2D-пакетов через text-to-image (nano-banana-2, gpt-image-2.5, remove_background).** Один ключ на Claude Code и Codex, хранится в окружении. Игра остаётся 2D. · Директор (подписка есть).
- 2026-10-17 · **Роли.** Директор — решения, вкус, приёмка. ChatGPT — текст сценария (единственный владелец) и три образца стиля с Директором. Claude Code — репозиторий игры. Codex — `pipeline/` (3D, рендер, 2D-пакеты, озвучка) и независимый плейтест. Контракт — `assets/manifest.json`. · Директор.
- 2026-10-17 · **Озвучка обязательна.** ИИ-голоса «как живые». Кастинг рано (Тихон первым), массовая запись только после `text_freeze: true`. Кандидат № 1 — ElevenLabs (русский в v4/v3/Multilingual v2, Text-to-Dialogue, коммерческая лицензия с плана Starter). · Директор.
- 2026-10-17 · **Без календарных обещаний.** Вехи закрываются критериями и приёмкой Директора, а не датами. · Директор.
- 2026-10-17 · **Ключ Meshy, показанный в чате, остаётся в работе**; перевыпуск только если перестанет работать. Хранится в окружении, в репозиторий не попадает. · Директор.
- 2026-10-17 · **Своя адвенчур-прослойка, Popochiu не берём.** Проба M0 дала комнаты, ходьбу с глубиной и перекрытием, хотспоты, выходы, флаги, сохранения и зеркало за одну сессию, всё текстовыми файлами и под тестами; Popochiu добавил бы зависимость от GUI-дока и миграций без выигрыша. Код Popochiu (MIT) остаётся источником приёмов. Директор может переоткрыть. · Claude Code, после M0.
- 2026-10-17 · **M0 принята предварительно** («с первого взгляда всё норм»); замечания по чеклисту ACCEPTANCE_M0 принимаются и позже. · Директор.
- 2026-10-17 · **Эпоха и место: Русский Север, условно 1900–1920-е, без точной даты.** Не сказочная «старая Русь»: без кокошников, лубка и стилизованной речи. Речь — живая современная с северным словарём; старшие чуть народнее, Агата нейтральнее, Тихон канцелярский. · Директор (выбором костюма Агаты v2), предложение Claude.

Ключ — секрет репозитория; результаты коммитит бот. Пока Codex не подключён, `pipeline/` пишет Claude Code (граница владения временно снята). · Директор («поищи ещё способ»), реализовано Claude Code.

- 2026-10-17 · **Цели журнала и любой текст для игрока не содержат кодов эпизодов и комнат** (`E6`, `O2`); порядок M06 → M07 закреплён флагом `seen_class_traces`; Q04 только в H1. · Claude Code.

- 2026-10-17 · **Кастинг голосов E0–E1 (ElevenLabs, My Voices):** Агата — «Agata» (не «Агата»), Тамара — «TAMARA-1», Пелагея — «PELAGEYA», Тихон — «CAT-2» (не первый «CAT»). Модель `eleven_v4` (по документации — самая выразительная, русский есть, аудиотеги исполняет лучше v3). Реплики — сразу в игру (`VoiceDirector`), без отдельных склеек для прослушивания. · Директор (23:45), реализовано Claude Code.
- 2026-10-18 · **Теги подачи — данные, не текст:** поле `tags` у реплики (тег перед фразой) и `voice_text`, если тег внутри фразы; слова сценария и субтитры без тегов; список разрешённых — `pipeline/voice/tags.json`; смена тегов перегенерирует только эту реплику (`voice_sha1`), игра сверяет sha1 текста субтитров. Обычно 0–1 тег (`Docs/VOICE_DIRECTION.md`). · Директор (теги из интерфейса), ChatGPT (режиссура), Claude Code.
- 2026-10-18 · **Закадровый голос «ZAKADR» (роль `narrator`)** озвучивает фразы субтитров, которые никому не принадлежат: осмотры, действия, реакции закрытых выходов, вопросы выбора, сообщения крупного плана загадки и строки предметов сумки (звучат после задержки курсора на кармашке ≈0,6 с, тот же предмет — не чаще раза в 30 с). Не озвучиваются: интерфейс и подсказки (`ui.*`), подписи плана (`map.*`), подписи хотспотов/выходов (`label*`), варианты выбора (`opt_*`), подписи загадки (`slot_*`, `marks`, `drawing`, `title`, `hinge`, `check`), служебная граница эпизода `Z3.exit_M1.closed` — список в `data/story/voice.json` → `narration`. Запись E0–E1 (90 фраз) — исключение из «массовая запись после `text_freeze`» по прямому заданию Директора, с потолком в запросе (`order`: 100 файлов, 6 000 символов). Вопросы выбора (`prompt`) озвучены по смыслу — это мысли Агаты в окне субтитров; убрать — добавить `prompt` в `skip_fields`. · Директор (задание 18.10), реализовано Claude Code.
- 2026-10-18 · **Мысли Агаты от первого лица — голосом Агаты, не ZAKADR** (п. 75: мужской баритон не может сказать «нарисовала я» — дефект, не вкус). Отбор — грамматическое первое лицо вне кавычек (я/меня/мой/наш…, «узнаю», «оставлю», «помню»…); цитаты героев в пересказе остаются закадровыми. Список — `data/story/voice.json` → `narration.by_speaker.agata.keys` (23 ключа, 20 записаны; `H1.photo.look` отложен — недостижим, `O2.mitten.*` — без ссылок), подача — `cast.json` → `agata.inner_voice` (тише и ближе, без шёпота), id в манифесте `agata:<ключ>`. Записи ZAKADR этих ключей остаются запасными: убрать ключ из списка — снова закадровый голос. `tools/validate_voice.py` падает, если строка закадрового голоса говорит от первого лица (`narration.first_person`). · Координатор (решение по п. 75), реализовано Claude Code.
