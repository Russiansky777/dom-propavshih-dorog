Формат: дата · решение · причина · кто принял. Переоткрывать только с новыми фактами. Открытые вопросы — внизу.

## Принятые

- 2026-10-17 · **Движок Godot 4.7.x, GDScript.** Браузер (itch.io) + Windows/macOS/Linux из одного проекта. C# отпадает: нет веб-экспорта (официальный прототип без сроков). Текстовые .tscn/.gd, CLI, GdUnit4 — агент может собирать и проверять без человека. · Разбор от 17.10, принято Директором («приступаем»).
- 2026-10-17 · **Контент как данные.** Сценарий живёт в `data/story/*.json`; `tools/validate_story.py` — обязательная проверка перед коммитом. Литературный текст в `story_source/` только читается. · Claude Code.
- 2026-10-17 · **Meshy — источник персонажей и переезжающих предметов (3D → спрайты), а также 2D-пакетов через text-to-image (nano-banana-2, gpt-image-2.5, remove_background).** Один ключ на Claude Code и Codex, хранится в окружении. Игра остаётся 2D. · Директор (подписка есть).
- 2026-10-17 · **Роли.** Директор — решения, вкус, приёмка. ChatGPT — текст сценария (единственный владелец) и три образца стиля с Директором. Claude Code — репозиторий игры. Codex — `pipeline/` (3D, рендер, 2D-пакеты, озвучка) и независимый плейтест. Контракт — `assets/manifest.json`. · Директор.
- 2026-10-17 · **Озвучка обязательна.** ИИ-голоса «как живые». Кастинг рано (Тихон первым), массовая запись только после `text_freeze: true`. Кандидат № 1 — ElevenLabs (русский в v4/v3/Multilingual v2, Text-to-Dialogue, коммерческая лицензия с плана Starter). · Директор.
- 2026-10-17 · **Без календарных обещаний.** Вехи закрываются критериями и приёмкой Директора, а не датами. · Директор.
- 2026-10-17 · **Базовое разрешение 1920×1080, canvas_items, keep aspect; Compatibility-рендерер** (нужен для веба). · Claude Code.

- Полное 3D в движке (первое лицо или фиксированная камера) — не для v1; 3D только как источник 2D.
- Ресурсный крафт, выживание, таймеры, процедурные забеги, стирание прожитых лет.
- Имя «Дарья» для жены Ильи.
