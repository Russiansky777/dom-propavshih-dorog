Прочитай AGENTS.md, CLAUDE.md, data/story/characters.json и pipeline/README.md. Задача — кастинг голосов для трёх персонажей, Тихон первым. Ничего в game/, data/ и Docs/ кроме своего отчёта не менять.

1. Возьми реплики из data/story/scenes/E0.json и E1.json (поле mandatory_lines): для Тихона — «На сухое мокрое не кладут», «Печь тоже здесь», «Ушла к Нине. До деревни — ещё нет»; для Нины — из E4.json «Я считала, сколько тебе теперь должно быть», «А мы прожили двадцать», «У меня там тоже дом. Теперь можно будет приходить».
2. Для каждого персонажа подбери 3 разных голоса из библиотеки ElevenLabs (русский; для Тихона — не детский и не мультяшный, а серьёзный маленький чиновник; для Нины — 60+; для Агаты — 25, негромкая, собранная). Используй самую свежую модель с русским (по документации: Eleven v4 или v3; если v4 недоступен по плану — Multilingual v2). 3. Сложи файлы в assets/voice/casting/<character>/<voice_name>_<n>.mp3, нормализуй громкость до −16 LUFS, обрежь тишину по краям.
4. Запиши Docs/VOICE_CASTING.md: таблица персонаж × голос (voice_id, модель, настройки, стоимость в символах/кредитах), твоя рекомендация с одной причиной на голос, и что Директору слушать первым. Провенанс — в Docs/ASSET_PROVENANCE.md.
