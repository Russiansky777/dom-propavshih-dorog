# План проверок

Три уровня, все запускаются из командной строки; реальные клики и полное прохождение подтверждают результат, не скриншот.

## 1. Данные сценария — `python3 tools/validate_story.py`
Ссылочная целостность; единственный источник предметов; симуляция основного пути без тупиков; достижимость локаций в момент доступности; окна V/Q до точки невозврата; тайны не раньше своего эпизода; счётчики переправ и глаголов загадок. Код 0 обязателен перед коммитом в `data/story/`.

## 2. Headless-тесты Godot — `tools/run_tests.sh`
GameState: сохранение → изменение → загрузка восстанавливает флаги, инвентарь, комнату. RoomManager: смена комнаты, спавн, автосохранение. Room.apply_flags: состояния узлов по флагам. Навигация: путь внутри полигона существует. Бот-проходчики дней (test_day_one, test_day2, test_day3) проходят игру через игровой API; полный список — раздел 4.

## 3. Сборка и визуальная проверка — `tools/export_web.sh`, `node tools/screenshots.mjs`
Веб-экспорт (single-threaded), статический сервер, headless Chromium, сценарий кликов по реальным координатам канваса, скриншот после каждого шага в `build/shots/`, консоль в `build/shots/console.log`. Директор смотрит скриншоты и играет по ссылке.

## Что проверять после каждого игрового изменения (из handoff)
- Обязательный предмет не исчезает навсегда и не выдаётся дважды.
- Любая необходимая цель объяснена до требования её выполнить.
- Кабинет, мельница, пристань и персонажи введены через понятный маршрут или разговор.
- Зеркало показывает правильное место и правильное состояние.
- После ухода и возвращения сохраняются двери, ремонт, знания, последствия выбора.
- Сохранение/загрузка не повторяет одноразовые события и не блокирует продвижение.
- Диалог не сообщает позднюю тайну раньше нужной сцены.
- Пропущенное Q не делает финал технически небезопасным.
- Предмет виден и выбирается мышью; текст читается; подсказка без угадывания пикселя.
- Агата правильно проходит перед объектами и за ними, не скользит, не застревает.
- Для невозможного сейчас действия есть понятная реакция.

## Правило дефекта
Каждый найденный дефект (плейтест Codex, Директор, бот) превращается в автопроверку уровня 1–3 до закрытия.
