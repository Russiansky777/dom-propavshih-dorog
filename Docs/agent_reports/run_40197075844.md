2. **Blender** — `pipeline/3d/npc_v2/build_npc.py` (параметры — поле `blender` в `pipeline/requests/npc_<имя>_b.json`):
   - Text to Motion на риге Meshy «сажал» фигуру (колени согнуты, таз назад) — ноги ×0,8 и таз ×0,6 к позе покоя, стопы на пол;

   - **рот**: кость `Jaw` (у рига Meshy лицевых костей нет — вместо ключа формы, тот же результат и проходит через glTF и рендер

     `rigid` готово). У Тамары по листу v2 сумки нет («No bag» в README листа), у Пелагеи на листе нет фонаря.
