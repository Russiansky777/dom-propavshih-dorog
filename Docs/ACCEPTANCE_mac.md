# Приёмка 26.11: версия для Mac

Что проверяем: ваше «Сделай версию для мак» 26.11 — файл, а не Steam. Это та же игра, что сборка № 222 для Windows
(после неё в самой игре ничего не менялось), собранная для Mac: одна программа и для Mac на Apple Silicon (M1, M2, M3, M4…),
и для Mac на Intel.

## Где проверять

- **Файл** — https://github.com/Russiansky777/dom-propavshih-dorog/releases/download/latest/DomPropavshihDorog_mac.zip
  (969 МБ; там же, где exe: https://github.com/Russiansky777/dom-propavshih-dorog/releases/tag/latest).
- Что это та самая сборка: на титульном экране внизу справа — «сборка 611d79e · 26.11 11:04» (время по часам Mac).
- Нужен macOS 13 Ventura или новее на Apple Silicon; macOS 11 Big Sur или новее на Intel.

## Как открыть (первый раз)

Программа подписана, но не заверена Apple (для этого нужен платный аккаунт разработчика Apple — 99 долларов в год), поэтому
при первом запуске Mac спросит разрешение. Один раз:

1. Скачать zip и открыть его двойным щелчком — рядом появится программа «Dom propavshih dorog». Её можно перетащить в
   «Программы».
2. Открыть её двойным щелчком. Mac скажет, что не может проверить программу, — нажать «Готово».
3. «Системные настройки» → «Конфиденциальность и безопасность» → прокрутить вниз: «Программа „Dom propavshih dorog“
   заблокирована…» → «Всё равно открыть» → подтвердить паролем или Touch ID.
4. Дальше игра открывается обычным двойным щелчком.

На macOS 14 и старше можно проще: правый щелчок по программе → «Открыть» → «Открыть».

**Если Mac пишет «программа повреждена, переместите в Корзину»** (так было 26.11 у тестера Dominik, файл пришёл через
Telegram; по-словацки «Súbor … je poškodený a nie je možné ho otvoriť»): файл цел — так Mac встречает незаверенные
программы из интернета, и в «Конфиденциальности и безопасности» её не видно. Помогает одна команда: «Терминал» (поиск
Spotlight) → набрать `xattr -cr` и пробел → перетащить в окно Терминала саму программу «Dom propavshih dorog» (значок, а не
папку Contents внутри) → Enter → открыть двойным щелчком. Устанавливать ничего не нужно: программа и есть игра.

Для тестеров по-английски: *Open Terminal (Cmd+Space, type “Terminal”), type `xattr -cr` followed by a space, drag the
“Dom propavshih dorog” app icon into the Terminal window, press Enter, then double-click the app. There is no installer —
the app itself is the game.*

## Что проверено до вас

На двух настоящих Mac от GitHub (Apple Silicon M1 и Intel, macOS 15), прогоны `build-mac` 45802727347, 45804606430 и
45805767595 (сборка — 45797080285), журнал и снимки — ветка `mac-checks`:
- программа universal (Apple Silicon и Intel), подпись цела (`codesign --verify`), Steam-часть загружается (без клиента
  Steam просто не включается);
- без окна на обоих Mac: титул и эпилог с маминой лентой — 40 и 60 с работы без единой ошибки скриптов;
- с окном на Apple Silicon: титул и комната «Зимний класс» с живыми Агатой и Ниной — снимок
  `Docs/evidence/mac_2611/apple_silicon_klass.png`;
- с окном на Intel картинку проверить не удалось: у виртуальной машины GitHub нет видеокарты для OpenGL — ни напрямую
  (программная отрисовка «Apple Software Renderer», окно чёрное), ни через ANGLE («Can't create an EGL display»). Сама
  игра там работает: без окна — без ошибок, Steam-часть загружается. На настоящем Intel-Mac видеокарта своя — если у вас
  Intel, строки 1–2 это и проверят.

## Что оценивать не нужно

- Steam: внутри есть, но без AppID не включится — для файла он не нужен.
- Предупреждение Mac при первом запуске — так у всех незаверенных программ; убрать его можно только платным аккаунтом Apple
  (ваше решение).
- Точки старта (.bat) — только для Windows.

## Как ответить

Номер строки и «ок» или что не так. И напишите, какой у вас Mac (Apple Silicon или Intel) — для Intel проверю отдельно.
