# H59 — промпт для ChatGPT: старорусская правка всех текстов и глоссарий

**Когда:** после партии H (T1–T3).

**Файл для ChatGPT:** `Docs/text_export/ru_all.tsv` — его выгружает T3.

**Что вернётся от ChatGPT:**
- `ru_all_new.tsv` — те же строки, плюс колонка `new_text`;
- `glossary.tsv`.

Агент на API загрузит их скриптом `tools/import_texts.py`.

---

Тот же проект «Дом пропавших дорог» (Русский Север, 1900–1920-е; сюжет на одной странице — SCENARIO_A4.pdf). Приложен файл `ru_all.tsv` — все тексты игры: id, кто говорит, где, контекст, текст.

Задача: переписать тексты так, чтобы они звучали как речь Русского Севера начала XX века: деревенские, северные и дореволюционные слова и обороты, простой живой разговор. Это не древнерусский язык. Смысл каждой строки сохраняется, длина — примерно та же (это субтитры и озвучка).

Правила:
1. У каждого своя речь:
   - Агата — гимназистка из уездного города, говорит грамотно, но с домашними словами;
   - Нина — учительница;
   - Павел — сухой мельник;
   - Пелагея — лодочница, практичная;
   - Тамара — почтальонша;
   - Ульяне 8 лет;
   - Тихон — ворчливый ленивый печной зверёк с сарказмом.
   - Рассказчик — спокойный, чуть книжный.
2. Речь в целом сделать старее — порядок слов, обороты, обиходные слова того времени — во всех строках. Особых, исконно старых слов — 15–25 на всю игру, не больше одного на реплику. Каждое такое слово пометь в `new_text` так: `[[слово|современное значение]]`, например: «Подай [[ухват|рогатина для чугунков в печи]]». В игре оно будет выделено, а при наведении покажется значение.
3. Только настоящие слова из словарей: «Толковый словарь живого великорусского языка» В. И. Даля, «Словарь вологодских говоров», «Словарь русских народных говоров». Не выдумывать. Если не уверен, что слово есть в словаре, — не используй его.
4. Не менять:
   - id;
   - имена (Агата, Нина, Илья, Ульяна, Митя, Пелагея, Павел, Тамара, Тихон, Дуня, Варвара, Фёдор Лукич);
   - названия мест (Ольховка, Заречье);
   - всё в фигурных скобках `{…}` и угловых `<…>`;
   - надписи интерфейса из колонки «где» = UI: их — только по смыслу, коротко, без старых слов.
5. Тётя: в первом упоминании «тётя Дуня — Евдокия, мамина сестра», дальше только «Дуня».
6. Не трогать строки, где текст — название кнопки, клавиши или числа.

Верни два файла:
- `ru_all_new.tsv` — все строки исходного файла в том же порядке, плюс колонка `new_text`. Если строку менять не нужно — повтори текст без изменений.
- `glossary.tsv` — колонки: слово, значение сейчас, словарь-источник (название и, если можешь, том и страница или статья), пример строки (id).

В конце напиши, сколько строк изменено, сколько старых слов и в каких строках ты не уверен.
