## Чтобы не оборваться снова
- **Никогда** не убивай процессы широкими шаблонами: `pkill node`, `pkill -f claude`, `killall`, `kill 0`, `kill -- -PID`. Этим ты убиваешь сам себя. Останавливай только свой процесс по его PID (Godot, Xvfb, ffmpeg).
- Долгий рендер запускай в фоне с журналом и пределом времени: `nohup timeout 5400 tools/trailer_render.sh … > /tmp/render.log 2>&1 &`. Потом проверяй журнал короткими командами (`tail`, `ls`), а не одной командой на час.
- Рендер — по планам, каждый в свой каталог. Если что-то упадёт, перерендеривай только этот план.
- Промежуточные коммиты делай после каждого готового этапа: план, скрипты, первый черновой mp4 в релизе.
