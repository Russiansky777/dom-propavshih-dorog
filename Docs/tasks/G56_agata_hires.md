## G56 — Агата чётче
Причина мягкости (данные): кадр Агаты в листах ~136×336 px (ячейка 384, game/assets/characters/agata/sprites.json), а в комнатах её растягивают ×2–3 (`depth.scale_bottom` в data/story/rooms/*.json: H2 3,07, M3 2,83, Z1 2,65, O3 2,45). Фон растянут ~×1,15.
Сделать:
1. Перерендерить все клипы Агаты (idle, walk, open, pick, reach, sit) в 2,5× разрешении: поле `render_size` в pipeline/requests/agata_v3.json (одно поле — так устроено). Конвейер — pipeline_character.yml (запуск через `gh workflow run`, дождаться одним `gh run watch`), стопы (feet fix) и проверки листов — как раньше. Кредиты Meshy не тратить (новых клипов не нужно).
2. Игра должна понимать разрешение листа: поле `texture_scale` (или аналог) в sprites.json → спрайт масштабируется на 1/k, Агата остаётся того же роста на экране; пиксели на метр и все проверки (ширина действий, совпадение с idle, отпечатки шагов) — с учётом k. Тест: рост Агаты на экране в каждой комнате тот же, что до перерендера (±1 px).
3. Вес: Steam — полное качество; веб должен работать нормально (Директор: «пусть весит больше, если надо»). Проверь размер веб-сборки (`tools/export_web.sh`, итоговые файлы): один файл не больше 200 МБ (предел itch.io по словам модератора), сайт не больше 1 ГБ (GitHub Pages). Если не влезает — сжатие текстур только для веба (настройки импорта/экспорта Godot), без потери чёткости на десктопе.
4. ИИ-проверка спрайтов (ai-sprite-qa) по новым листам — 0 критичных.

## G10 — платок на крючок
Когда Агата забирает мокрый платок с лежанки в H1, вместо мгновенного исчезновения: Агата подходит к лежанке → действие `pick` → идёт к вешалке у двери → действие `reach` → платок появляется на левом крючке (слой H1_state_towel_hook уже есть). Постановкой из существующих действий и ходьбы (данные сцены/хотспота), без новых клипов. Игрок может прервать кликом — результат тот же (флаг, слой).
