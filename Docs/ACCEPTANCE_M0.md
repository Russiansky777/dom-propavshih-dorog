# Приёмка M0 — чеклист для Директора

Где проверять:
- **Вариант А (быстрее)**: `DomPropavshihDorog.exe` из чата — запустить, ничего не устанавливать.
- **Вариант Б (полнее, у вас есть Godot)**: `git clone https://github.com/Russiansky777/dom-propavshih-dorog`, открыть `game/project.godot` в Godot **4.7.x** (проект сделан в 4.7.2; более старая версия предложит конвертацию — отказаться и обновить Godot), нажать F5. Так видно и проект, и консоль.

Управление: левый клик по полу — идти; клик по объекту — подойти и применить; F5 — сохранить, F9 — загрузить; кнопка New game — сброс.

## Критично (без этого веха не принимается)

| № | Что сделать | Как должно работать | Ок? |
| --- | --- | --- | --- |
| 1 | Кликнуть в разные точки пола, в том числе за столом и перед ним | Агата идёт к точке, не скользит (шаг меняется с движением), **становится меньше у дальней стены и больше у переднего края**; перед столом она перекрывает стол, за столом — стол перекрывает её | |
| 2 | Кликнуть на стену или на зону вне пола | Агата не идёт в стену; доходит до ближайшей точки пола или не реагирует — но не застревает и не проходит сквозь стол | |
| 3 | Посмотреть в зеркало до клика по раме | В раме — **другая комната** (серый кабинет), изображение **дрожит**, в нём ходит фигура туда-сюда | |
| 4 | Кликнуть по раме зеркала | Агата подходит, дрожание **прекращается**, внизу подсказка «Зеркало закреплено на стене. Стекло успокоилось», в HUD появляется `mirror_mounted=1`; фигура в зеркале продолжает двигаться | |
| 5 | Кликнуть по стрелке справа | Переход в кабинет (RoomOffice): холодные цвета, та же фигура (эхо) ходит в живую, засов на стене закрыт | |
| 6 | Кликнуть по засову | Засов открывается, в HUD `office_latch_open=1` | |
| 7 | Стрелка слева — назад в дом | Дом в прежнем состоянии: зеркало закреплено (не дрожит), **дверь на стене теперь открыта** (состояние комнаты изменилось по флагу из другой комнаты) | |
| 8 | F5 → New game → F9 | После New game всё сброшено (зеркало дрожит, дверь закрыта, флагов нет). После F9 — **возвращаются флаги, комната и позиция Агаты** | |
| 9 | Закрыть игру, запустить заново, нажать F9 | Состояние восстановилось из файла на диске (не только из памяти) | |

## Важно (замечания записываем, веху не блокируют)

| № | Что посмотреть | Ожидание | Заметки |
| --- | --- | --- | --- |
| 10 | Скорость ходьбы | Спокойная, «прогулочная»; не раздражает на длинных переходах | |
| 11 | Отклик на клик | Нет ощущения задержки; повторный клик во время ходьбы перенацеливает | |
| 12 | Зеркало | Живой вид второй комнаты в раме читается как «окно в другое место», а не как телевизор | |
| 13 | Окно/масштаб | При изменении размера окна картинка не искажается (чёрные поля допустимы) | |

## Что здесь НЕ нужно оценивать
Графика — заглушки, сделанные скриптом. Персонаж — цветной прямоугольник. Звука нет. Тексты HUD — технические. Всё это меняется в M1 и далее.
