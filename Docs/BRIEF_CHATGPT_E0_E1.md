# Бриф для ChatGPT — арт и текст эпизодов E0–E1

Скопировать в чат ChatGPT целиком, приложив три утверждённых эталона из `assets/reference/`: `agata_sheet.png`, `tikhon_sheet.png`, `H1_bg.png` (+ `H1_fg_table_chair.png`). Всё новое должно выглядеть так, будто нарисовано той же рукой при том же свете. Порядок пунктов — порядок пользы: первые нужны игре раньше.

---

Мы делаем 2D point-and-click «Дом пропавших дорог» (Godot, кадр 1920×1080, фоны рисуем 2048×1152). Эталоны стиля утверждены — приложены: лист Агаты, лист Тихона, жилая комната H1 со столом отдельным слоем. Новые картинки должны совпадать с ними по манере (мягкая живопись, видимый мазок, тёплый свет дома, холодный свет потерянных мест), по высоте камеры и горизонту (~45 % высоты кадра, как в H1), по степени детализации.

Мир: Русский Север, условно 1900–1920-е, без точной даты. Не сказочная «старая Русь»: без кокошников, лубка и стилизации. Снаружи (Заречье) вещи купленные и обычные; внутри (Ольховка, школа) — те же вещи, но переделанные и чиненные за двадцать лет. Канон: Агате 18.

Общие правила для всех фонов:
- В центре пола — свободная полоса для ходьбы, мебель и предметы переднего плана НЕ на фоне, а отдельными PNG с прозрачным фоном в том же ракурсе и свете (за ними будет проходить героиня).
- Без людей, курсоров, подписей, интерфейса. Без снега в воздухе, огня, пара и света ламп как объектов — это рисует код; снежный покров и неподвижные вещи — рисовать.
- Один источник света на комнату, направление указано в пункте.
- Для каждого файла: имя файла из пункта, размер, модель и версия, что не получилось точно (прозрачность, размер) — сказать прямо, не подгонять.
