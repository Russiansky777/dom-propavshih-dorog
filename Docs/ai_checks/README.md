# ИИ-проверки в Actions

Небольшой набор проверок на Claude API. Каждая запускается только когда меняются её входы, пишет короткий отчёт в `Docs/ai_checks/<проверка>_<дата>.md` (коммит с `[skip ci]`) и **никогда не правит game/ и data/** — находки разводит координатор. Ключ — секрет `CLAUDE_API`, рабочее пространство — `CLAUDE_WORKSPACE`; в публичный лог Actions не печатаются ни ключ, ни ID, ни ответы модели. Код — `tools/ai_checks/`, API и цены — `tools/ai_playtest/claude.mjs`. Плейтест (ворота перед передачей Директору) — `Docs/playtest/README.md`.

Ручной запуск любой проверки: поменять поле `run` в `Docs/ai_checks/requests/<проверка>.json` и запушить (или Actions → нужный workflow → Run workflow).

| Проверка | Когда запускается | Что смотрит | Отчёт |
| --- | --- | --- | --- |
| Спрайты (`ai_sprite_qa.yml`) | после каждого прогона конвейера персонажей (`pipeline-character`, через `workflow_run`: его коммиты идут с `[skip ci]`); запрос `requests/sprite_qa.json` (`"chars": "all"` или список) | глазами модели — листы всех действий в 8 направлениях, низ фигуры ×2, опорные виды: стопы (носки врозь, сквозь ногу или подол, рывки опорной стопы), руки и сумка сквозь тело, текстура, направление, обрезка; линейка всех персонажей по росту — масштаб друг к другу и к возрасту. Проверяются только персонажи, чьи файлы спрайтов изменились (`sprite_qa_state.json`); числовые углы стоп — у другого агента | `sprite_qa_<дата>.md` + листы с находками в `sprite_qa_<дата>/` |
| Текст (`ai_text_lint.yml`) | пуш, меняющий `data/story/text/ru_*.json`, `scenes/*.json`, `flags.json`, `items.json`, `quests.json`, `locations.json`; запрос `requests/text_lint.json` | всё, что игрок читает и слышит: канон (возрасты, имена, «Дарья», Тихон, нет эха в конторе), опечатки, грамматика, пунктуация, единообразие имён и терминов, цель позже требования. По пушу — только новые и изменённые строки (весь текст — контекст); если видимый текст не менялся, API не вызывается | `text_lint_<дата>.md` |

Важность находок: **критично** — противоречит канону или искажает смысл; **важно** — ошибка, заметная игроку или в озвучке; **мелочь** — пунктуация и шероховатости.
