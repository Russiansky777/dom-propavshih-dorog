# Библия стиля — черновик для утверждения

Статус: не утверждена. Заполняется ChatGPT с Директором по трём опорным образцам (Агата, Тихон, жилая комната H1). До утверждения ни один ассет не производится массово.

## Направление
Мягкий рисованный мир: тепло дома, холод потерянных мест. От фотореализма концептов — на шаг к живописи: видимый мазок, мягкие края, меньше микродеталей. Причина: на фотореалистичном фоне любая анимированная героиня выглядит «бумажной». Без угловатой и рубленой стилизации.
