# Время суток по сценам (F17)

Замечание Директора 23.10: «ещё раз подумать над временами дня, чтобы они скоординированно со сценарием и логикой сменялись». Основа — `Docs/SCENARIO_FINAL.md` §5–8 (хронология, дни 1–4, эпилог). Данные — `data/story/time/` (истина для игры), эта таблица — для чтения; тест `game/tests/test_time_of_day.gd` сверяет её столбец «Состояние» с данными.

**Правило.** Время не хранится в сохранении: оно выводится из флагов `done_<сцена>` основной истории (их никто не снимает) — последнее по порядку состояние, чьё условие выполнено. Поэтому внутри дня время не идёт назад, загрузка ничего не «перематывает», а каждая сцена начинается ровно в одном состоянии.

**Погода.** Заречье дни 1–4 — пасмурная поздняя осень, морось, ветер с реки (живой мир `data/story/ambient`, пресет `street`). Ольховка — снежная зима с первого взгляда: из класса (за окном снег, M06), с причала, как только канат сел на кольцо (тот берег белеет, `R1 far_snow`, M15), и всё, что за переправой. Эпилог — зима на обоих берегах.

## Как это сделано (для агентов)

- **Состояния** — `data/story/time/_index.json → states` (по порядку: `id`, `day`, `phase`, `label` — строка журнала, `when` — флаги, с которых состояние начинается). `scenes` — сцена → состояние (тест сверяет).
- **Виртуальные флаги** — любое существующее условие (`if`/`unless` слоёв, эффектов и света, `energy_if`, `visible_if`/`hidden_if` хотспотов, `if` реплик) может проверять время без кода: `tod_<состояние>` (`tod_d2_dusk`), `tod_<фаза>` (`tod_morning`, `tod_dusk`, `tod_evening`, `tod_night`, `tod_day`, `tod_midday`, `tod_afternoon`), `tod_day1`…`tod_day4`, `tod_day5` (эпилог), `tod_dark` (сумерки, вечер, ночь). В сохранение не пишутся.
- **Оттенок комнаты** — по классу комнаты (`grades`: `exterior`, `interior`, `cut_exterior`/`cut_interior` — места за разрезом, `frame` — кадры); свой файл `data/story/time/<LOC>.json` переопределяет: `grade` по состоянию или фазе (`{"tint": "#rrggbb"}` или `"painted"` — как нарисовано), `class`, `replaces_effects` (старые оттенки комнаты, которые время заменяет), `windows` (тёплые окна: `rect`/`points`, `color`, `alpha`, `halo`, `if`/`unless`, по умолчанию `tod_dark`), `fixed_state`.
- **Как красит.** Комната со светом (`data/story/lights/<LOC>.json`) — ambient-источником по состоянию (арт темнеет, огонь печи и фонари остаются яркими, фигуры берут тон); без света — одним полигоном-умножением на весь кадр (под моросью и метками выходов). Смена состояния в комнате — плавно за 2 с; вход, загрузка, новая игра — сразу конечный вид.
- **Журнал** — строка под заголовком: «День второй · сумерки» (в отрезанном классе — «… — в классе своё время: там зимний день»).
- **Проверки** — `tools/validate_time.py` (порядок состояний, флаги условий существуют и ставятся основной историей, сцены основной истории — каждая ровно в одном состоянии, оттенки и окна в кадре, ключи текста), `game/tests/test_time_of_day.gd` (время не идёт назад внутри дня по всей основной истории; каждая сцена — своё состояние; оттенок и окна в комнатах по состояниям; загрузка — сразу конечный вид; журнал).

## Для агента Блоков 3–5 (дни 3–4, эпилог)

1. Ваши комнаты уже получают время по умолчанию: O3/O4/S1/O1/O2 — класс `cut_*` (ночь второго дня — как нарисовано, утро/день/вечер третьего дня — оттенки `interior`/`exterior`), R3 и R2 — `frame` (нарисованы вечером, не тонируются), кадры EP_*/F_* — `frame`. Если в комнате есть своя ночь/утро слоями (O4 `night`, O3 `effects.night`) — это работает как раньше.
2. Слои «утро/ночь» можно переключать временем, а не своими флагами: `"unless": ["tod_night"]`, `"if": ["tod_d3_evening"]`, свет — `"if": ["tod_dark"]`. Флаги `morning_day3`, `day3_done` и т. п. не трогаем — время из них не выводится.
3. Своё мнение о свете комнаты — файлом `data/story/time/<LOC>.json` (`grade` по состоянию, `"painted"` — где кадр уже нарисован под это время; `windows` — горящие окна вечером; `replaces_effects` — если ваш эффект-оттенок стоит заменить временем). Проверка: `python3 tools/validate_time.py`.
4. Дни 3–4 днём (партия 8, 23.10): переправа R2 и дальняя опора R3 — дневные кадры (слой `day`, `"unless": ["tod_day1", "tod_day2", "tod_d3_evening"]`, рябь — копии водных областей с `source: layer:day`); поворот Z3 — `water_low_day` (спущенная вода днём, вместо `water_low` / `stone_no_plate*`, рябь `river_day_low`). Причал R1 днём при спущенной воде — пока прежний рисунок.
5. Вечер третьего дня (`d3_evening`) начинается, когда сделаны все четыре M23а–г, и держится до конца M24; день четвёртый — после `done_M24`. Если порядок сцен поменяется — поправить `when` в `_index.json` и столбец `scenes`, тест покажет расхождение.
