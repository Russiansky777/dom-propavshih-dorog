# «Дом пропавших дорог» — канон одной страницей

2D-игра «укажи и щёлкни», Русский Север, 1900–1920-е. Тексты — после старорусской правки (H59): речь Русского Севера начала XX века. Особые старые слова помечены `[[слово|значение]]` — в игре слово выделено, при наведении видно значение (не больше одного на реплику, 15–25 на всю игру, только из словарей Даля, вологодских говоров, «Словаря русских народных говоров»).

## Люди и возраст (на момент событий)
- **Агата** — 18 лет (17 при разрыве; жила вне Ольховки, гимназистка из уездного города). Главная героиня.
- **Нина** — 67, учительница, мать Агаты.
- **Илья** — 32, брат Агаты (старше сестры на 14 лет).
- **Ульяна** — 8.
- **Митя** — 37.
- **Пелагея** — 40, лодочница.
- **Павел** — 48, мельник.
- **Тамара** — 53, почтальонша.
- **Дуня** — тётя: при первом упоминании «тётя Дуня — Евдокия, мамина сестра», дальше только «Дуня». Умерла в 72 за два местных года до событий.
- **Тихон** — печной зверёк-смотритель с кошачьими повадками: ворчливый, ленивый, любит поесть, саркастичный. Не подсказчик, не питомец с уходом, не вор нужных предметов.
- Также: Варвара, Фёдор Лукич. Имя «Дарья» не используется.

## Законы мира
- «Вещи помнят место, которому служили. Дорогу держат с двух концов.»
- Снаружи прошёл год, внутри (в Ольховке) — двадцать лет. Прожитое не стирается: никакого омоложения, воскрешения, стирания детей.
- Время внутри идёт ровно в 20 раз быстрее, пока к месту не ведёт дорога, которую держат с двух концов; потом оно общее.
- Зеркало показывает нынешний вид со своего прежнего места. Не портал, не телефон, не машина времени.
- Эха в конторе мельницы нет: зеркало конторы показывает живого Павла сейчас (проверяется фонарём).
- Один технический финал: два постоянных входа, общее время. Личные выборы меняют детали, не судьбу деревни.

## Устройство игры (важно для логики)
- Дни: каждый день кончается сном.
  - День 1 — лежанка у Дуниной печи; там Нина видит Агату в зеркальце — это канон.
  - Дни 2–3 — кровать в доме Нины.
  - Кровать на чердаке — Дунина, Агата там не спит.
- Переход дня — затемнение и надпись «День первый / второй / третий / четвёртый».
- Обязательный предмет не исчезает и не выдаётся дважды. **Любая цель объяснена до того, как её требуют выполнить.**
- Журнал ведёт цели и подсказки; Тихон не подсказывает.
