# Приёмка M1 — чеклист для Директора

Что проверяем: эпизоды E0–E1 (от почты Тамары до надписи на школьной доске) проходятся целиком на заглушках, и всё, что происходит, идёт из данных сценария.

Где проверять:
- **Браузер (основное, всегда текущая версия):** https://russiansky777.github.io/dom-propavshih-dorog/ — после обновления сборки нажать Ctrl+F5. Номер версии: https://russiansky777.github.io/dom-propavshih-dorog/version.txt
- **Windows:** https://github.com/Russiansky777/dom-propavshih-dorog/releases/download/latest/DomPropavshihDorog.exe (та же версия; SmartScreen: «Подробнее» → «Выполнить в любом случае»).
- **Godot 4.7.x:** открыть `game/project.godot`, F5.

Управление — только мышь: клик по полу — идти; клик по подписанному прямоугольнику — подойти и осмотреть/использовать (один клик, без глаголов); клик по предмету в верхней панели — выбрать, затем клик по тому, к чему применить (повторный клик по предмету — отмена); клик по окну текста — дальше; кнопки «Журнал», «Подсказка», «Меню» вверху справа. F5/F9 — быстрое сохранение/загрузка.

Прохождение займёт 8–12 минут. **Все 10 комнат E0–E1 — на настоящем арте** (пакет ChatGPT), Агата, Тамара и Пелагея — 3D-модели Meshy, отрендеренные в 8 направлений. Подписи объектов на картинке не нарисованы: наведите курсор — появится название. Тексты осмотров — версия ChatGPT (владелец текста). Тихон — пока прямоугольник (листа в конвейере нет).
