# Приёмка M1 — чеклист для Директора

Что проверяем: эпизоды E0–E1 (от почты Тамары до надписи на школьной доске) проходятся целиком на заглушках, и всё, что происходит, идёт из данных сценария.

Где проверять:
- **Вариант А (быстрее)**: `DomPropavshihDorog.exe` из чата (сборка `build/windows/`) — запустить, ничего не устанавливать. Windows может показать предупреждение SmartScreen (сборка не подписана): «Подробнее» → «Выполнить в любом случае».
- **Вариант Б (полнее)**: открыть `game/project.godot` в Godot **4.7.x** и нажать F5. Данные сценария лежат копией в `game/data/story/` — ничего запускать заранее не нужно.
- Веб-версия: `build/web/` через любой статический сервер (или ссылка из чата).

Управление — только мышь: клик по полу — идти; клик по подписанному прямоугольнику — подойти и осмотреть/использовать (один клик, без глаголов); клик по предмету в верхней панели — выбрать, затем клик по тому, к чему применить (повторный клик по предмету — отмена); клик по окну текста — дальше; кнопки «Журнал», «Подсказка», «Меню» вверху справа. F5/F9 — быстрое сохранение/загрузка.

Прохождение займёт 8–12 минут. Все комнаты, кроме H1, — цветные прямоугольники с подписями; тексты осмотров — черновики (их заменит владелец текста).

**H1 (жилая комната) — настоящий фон и настоящая Агата.** Здесь подписи не нарисованы: наведите курсор — у объекта появится его название (печь — верх печи слева; ставня — окно справа; мокрая вещь — лавка между креслом и столом; чашки — полка с кувшинами; фотография — икона на стене; «снятая полка» — доска с крюками; крыльцо — дверь посередине). Выходы: правый край — мастерская, нижний край — галерея (левее) и чердак (правее). Проверьте заодно: Агата идёт влево — смотрит влево, вверх по экрану — спиной, вниз — лицом; стоя не поворачивается; за столом её ноги скрыты столом, перед столом — видна целиком; ближе к зрителю она крупнее и идёт быстрее.
