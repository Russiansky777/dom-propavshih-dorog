# Приёмка сборки 09.11 (вечер): вещи в руках, финальные кадры, ужин, жители

Что проверяем: правки по прохождению Директора 09.11 (11:34 «ключ приклеен на руку… Агата обходит Тамару»; 12:35 «Пелагея… у каната», «Тамара развернута к нам, сумка висит в воздухе», «Павел, Пелагея развернуты», «Уля не приходит на видео»; 12:40 «ремень сумки и лампу убрать»; 13:36 «убрать „лампу несёт“, сумку на бедро»).

## Где проверять

- **Игра:** релиз latest — https://github.com/Russiansky777/dom-propavshih-dorog/releases/tag/latest → файл `DomPropavshihDorog.exe` (один файл, ~1,2 ГБ; или `DomPropavshihDorog_win.zip`). Это сборка 09.11 вечером (run 42677910736); в ней всё ниже плюс управление с геймпада (Steam Deck) — его чеклист отдельно: `Docs/ACCEPTANCE_DECK.md`.
- **Точки старта:** архив `Tochki_starta.zip` (пришлю вместе со ссылкой; тот же, что днём) — распаковать рядом с `DomPropavshihDorog.exe`, двойной щелчок по нужному файлу. Старт с точки перезаписывает «Продолжить» (автосохранение); слоты 1–3 и «День второй / третий / четвёртый» не трогаются.
- **Порядок, чтобы пройти всё за один заход (~40 мин):**
  1. «Новая игра» → почта, Тамара → №1.
  2. Точка «03» → Пелагея у каната, Митя с фонарём, объятие на причале → №2, №3, №14.
  3. Точка «04» → вечер у Ильи, мама и зеркальце, объятие с мамой → №7, №8, №14, №15.
  4. Точка «06» → мел (№11); точка «07» → пальто (№9); точка «08» → нож (№10).
  5. Точка «09 Эпилог» → мост, мельница, причал, ужин → №4, №5, №6, №13.
  6. Английская версия: «Настройки» → «Озвучка: English» и «Субтитры: English», затем точка «04» → №12.

## Оценивать не нужно

- Модели жителей сами по себе (лица, одежда) — отдельное решение; здесь только движения (№15).
- На стыке петли раз в 10 с может быть едва заметный сдвиг текстуры — это предел видеоформата Godot (Theora), проверено; рывков раз в полсекунды быть не должно.
- Линукс-сборка в релизе старая (03.11) — не нужна.

## Как ответить

Номер и «ок» / что не так — сообщением, как обычно.
